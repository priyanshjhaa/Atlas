# Security policy

## Supported version

Atlas is currently under active development. Security fixes are applied to the
latest commit on `main`; older commits and feature branches are not supported
release lines.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include secrets,
tokens, private repository content, personal information, or exploit details in
an issue or discussion.

Report vulnerabilities privately through the repository's
[security advisory form](https://github.com/priyanshjhaa/Atlas/security/advisories/new).
Include the affected component, expected and observed behavior, impact, and the
minimum reproduction information needed to investigate safely.

If private reporting is unavailable, contact the repository owner without
sharing sensitive details publicly and request a private reporting channel.

Reports will be acknowledged when reviewed. Remediation timing depends on
severity, exploitability, and the scope of the affected deployment. Please
allow time for investigation and coordinated disclosure before publishing
details.
